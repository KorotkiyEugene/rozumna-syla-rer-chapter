# Радіоелектронна розвідка (РЕР): матеріали до розділу підручника

Це сайт до розділу «Радіоелектронна розвідка (РЕР)» шкільного підручника «Розумна Сила». Адреса сайту: <https://korotkiyeugene.github.io/rozumna-syla-rer-chapter/>

Для кожної теми розділу сайт має сторінку. На ній є вправа, яку виконують у браузері, аркуш для друку, матеріали до завдань і відповіді.

Сторінки працюють без реєстрації і без встановлення програм. Вони працюють і з копії на диску: достатньо відкрити файл `index.html`.

Сторінки складають скрипти з тих самих даних, що й розділ підручника. Тому файли цього репозиторію не редагують вручну: зміни вносять у скрипти й складають сайт наново.
